## 📌 Proje Hakkında

Bu depo; sıfırdan Python programlama dilini öğrenme ve veri bilimi kütüphanelerinde uzmanlaşma sürecinde oluşturulmuş **düzenli, açıklamalı ve modüler** kod notlarını içermektedir. 

Tüm konular teorik bilgiler, uygulamalı kod örnekleri ve gerçek veri setleri (`.csv`) üzerindeki analizlerle desteklenmiştir.
